# 🎮 Memory Game

A simple memory matching game built with **HTML, CSS, and JavaScript**.  
The game includes a video background 🎥, background music 🎵, and interactive colored tiles.

---

## ✨ Features
- Video background that fills the page  
- Background music with a "Play Music" button (user must click to enable sound due to browser autoplay rules)  
- Randomly shuffled color tiles  
- Flip tiles by clicking to reveal colors  
- Matching logic with flip-back if tiles don’t match
